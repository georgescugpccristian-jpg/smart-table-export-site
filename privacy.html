Privacy Policy

Local processing.
Clear choices.

Last updated: November 17, 2026

Smart Table Export processes website content to help you preview and export tables. This policy describes the current extension and this product website. The extension enforces a Free export allowance and uses Gumroad license keys to activate Pro. The Gumroad product is currently unpublished, and the extension is not yet publicly available on the Chrome Web Store. Purchases and installation are coming soon.

1. Table content and local processing

When you choose to find tables, the extension reads supported HTML tables on the active page. It processes table text, headers, captions, structure, and the page URL locally to identify tables, validate changes, show previews, and generate CSV or XLSX files. It does not continuously monitor your browsing.

The current extension does not upload table content, page URLs, export files, or preferences to external servers. The extension contains no analytics, advertisements, or telemetry. License activation and revalidation make external HTTPS requests to Gumroad; table processing does not. Removing a license is local. Website content and your export settings are processed on your device.

A scan snapshot remains in the extension's isolated page memory until it is replaced by a new scan, the page navigates, or its ten-minute cleanup timer expires. Popup previews and unsaved settings disappear when the popup closes. Closing the popup can interrupt an operation.

2. Saved export preferences

Preferences are stored only when you explicitly choose Save preferences. They use the browser's extension-local storage, restricted to trusted extension contexts, rather than Chrome Sync.

A saved record includes:

  • The website origin: scheme, hostname, and port where applicable.
  • A SHA-256 matching signature derived from the exact page pathname, ordered source headers, and column count.
  • Column selection and order, custom column names, header mode, XLSX numeric formats, and cleanup choices.
  • A storage schema version and column count.

Saved records do not contain table data rows, previews, raw source headers, raw pathnames, query strings, or URL fragments. The full page URL may be held transiently during a scan to reject navigation changes; it is not saved in preference records or sent to a server.

Website origins and custom names can reveal sensitive information. A hash is not encryption and does not make the saved information anonymous. Do not put confidential information into custom names unless you want it stored locally.

Creating, editing, and applying preferences require Pro. Free users can view the saved-preference website list and delete saved preferences. Saved preferences are applied only by your explicit action on a compatible table. They are not automatically applied. Persistent preference access is disabled in incognito mode; normal local exports can still work when the browser allows the extension there.

3. Retention, deletion, and exported files

Preferences remain until you delete them, clear extension storage, or uninstall the extension. They can survive browser restarts and clearing browsing history. Use Delete saved preferences on a table or Manage saved preferences to delete a website's preferences or all saved preferences. Resetting export settings does not delete saved records.

Local quota records contain the completed Free export count, pending reservations with random tokens, download IDs when known, and whether a download started as Free. Separate cleanup-pending records retain IDs for history cleanup after quota has been settled. Pending or uncertain downloads reserve Free slots. Missing history or an unknown launch result can leave a reservation in place; elapsed time alone does not release it. Quota data is not sent to Gumroad.

Downloaded files are saved through your browser to a location you choose or its configured download folder. They can contain sensitive website content. Deleting preferences or uninstalling the extension does not remove your downloaded files. Files that you later share, upload, or open in another service are subject to that service's practices.

4. Browser permissions

The extension requests activeTab to access the selected page when you invoke it, scripting for table detection and validation, storage for local preferences, licensing and quota records, and downloads to start local CSV/XLSX downloads, inspect their state, cancel interrupted transfers, and erase their download-history entries. Its host permission is limited to https://api.gumroad.com/* for licensing; it does not request general host access to every website or the separate history permission.

Downloads use local data URLs, which can temporarily expose exported table contents in browser download metadata. The extension attempts to erase its own completed download-history entries and confirmed non-resumable interrupted entries. Failed cleanup remains pending and is retried during reconciliation, including worker reload, browser startup, or subsequent use. Cleanup may be delayed by browser termination, storage errors, or browser API failures. Erasing a history entry does not delete the downloaded file or clear general browsing history.

5. Free quota and Pro licensing

Free includes five completed exports per browser installation, shared across CSV and XLSX, with no subscription or monthly reset. Smart Table Export – Lifetime License costs USD 7.99 as a one-time purchase through Gumroad. Pro provides unlimited exports, column customization, data cleanup, numeric Excel formatting, and saved preferences.

Pro activation and revalidation send the license key, public product ID, and increment_uses_count=false over HTTPS to api.gumroad.com/v2/licenses/verify. Requests omit browser credentials and do not send an email address, installation ID, table contents, page URLs, browsing history, exported files, saved preferences, or quota data. Gumroad receives ordinary connection information such as the IP address used for the request. Provider responses may contain customer or order information; the extension discards those details without displaying or logging them.

Trusted extension-local storage, rather than Chrome Sync, holds the provider, product ID, license key, active or invalid status, last successful verification time, and retry failure count/timing. License keys are not encrypted against someone with access to the browser profile. Revalidation normally occurs on use after seven days from the last successful verification; temporary failures retry on use with delays from one minute up to one hour. Cached Pro access ends no later than 30 days after the last successful verification. Temporary failures do not extend that time. A definitive rejection, including an invalid, disabled, refunded, disputed, or wrong-product license, disables Pro access.

You can remove a license locally at any time, including offline. Removal does not revoke the purchase or contact Gumroad; there is no remote activation slot to release. Uninstalling or clearing extension storage also removes local license state and may reset the local Free allowance. Older provider records are retained locally and do not activate Gumroad Pro access.

The extension and this website do not collect payment details. When checkout becomes available, purchases will take place separately on Gumroad and will be subject to its policies. See the Gumroad Privacy Policy. Checkout remains disabled on this website while the product is unpublished.

6. This website and GitHub Pages

This website uses static HTML, CSS, and locally hosted images. It contains no JavaScript, forms, analytics, advertising, cookies, browser-storage features, or tracking code. It does not read your tables or communicate with the extension.

When hosted on GitHub Pages, GitHub receives the requests needed to deliver these pages and assets. GitHub states that visitor IP addresses are logged and stored for security purposes. Hosting-related processing is separate from the extension's local table processing. See GitHub Pages documentation and the GitHub Privacy Statement.

If you follow a link to GitHub or another external website, that service's privacy practices apply. No table content or preference data is attached to links on this website.

7. Policy updates and project information

Changes to data handling will be reflected here with an updated date. Website source and project information are available in the public Smart Table Export website repository. Avoid posting private table contents, exported files, or sensitive website identifiers publicly.
