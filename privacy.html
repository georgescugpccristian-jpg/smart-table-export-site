Privacy Policy

Local processing.
Clear choices.

Last updated: November 13, 2026

Smart Table Export processes website content to help you preview and export tables. This policy describes the current extension and this product website. The extension enforces a Free export allowance and uses Lemon Squeezy for Pro licensing. This website does not offer a checkout.

1. Table content and local processing

When you choose to find tables, the extension reads supported HTML tables on the active page. It processes table text, headers, captions, structure, and the page URL locally to identify tables, validate changes, show previews, and generate CSV or XLSX files. It does not continuously monitor your browsing.

The current extension does not upload table content, page URLs, export files, or preferences to external servers. The extension contains no analytics, advertisements, or telemetry. License activation, validation, and deactivation make external HTTPS requests to Lemon Squeezy; table processing does not. This does not mean that no data is handled: website content and your export settings are processed on your device.

A scan snapshot remains in the extension's isolated page memory until it is replaced by a new scan, the page navigates, or its ten-minute cleanup timer expires. Popup previews and unsaved settings disappear when the popup closes. Closing the popup can interrupt an operation.

2. Saved export preferences

Preferences are stored only when you explicitly choose Save preferences. They use the browser's extension-local storage, restricted to trusted extension contexts, rather than Chrome Sync.

A saved record includes:

  • The website origin: scheme, hostname, and port where applicable.
  • A SHA-256 matching signature derived from the exact page pathname, ordered source headers, and column count.
  • Column selection and order, custom column names, header mode, XLSX numeric formats, and cleanup choices.
  • A storage schema version and column count.

Saved records do not contain table data rows, previews, raw source headers, raw pathnames, query strings, or URL fragments. The full page URL may be held transiently during a scan to reject navigation changes; it is not saved in preference records or sent to a server.

Website origins and custom names can reveal sensitive information. A hash is not encryption and does not make the saved information anonymous. Do not put confidential information into custom names unless you want it stored locally.

Creating, editing, and applying preferences require Pro. Free users can view the saved-preference website list and delete saved preferences. Saved preferences are applied only by your explicit action on a compatible table. They are not automatically applied. Persistent preference access is disabled in incognito mode; normal local exports can still work when the browser allows the extension there.

3. Retention, deletion, and exported files

Preferences remain until you delete them or uninstall the extension. They can survive browser restarts and clearing browsing history. Use Delete saved preferences on a table or Manage saved preferences to delete a website's preferences or all saved preferences. Resetting export settings does not delete saved records.

Local quota records contain the completed Free export count, pending reservations with random tokens, download IDs when known, and whether a download started as Free. Separate cleanup-pending records retain IDs for history cleanup after quota has been settled. Pending or uncertain downloads reserve Free slots. Missing history or an unknown launch result can leave a reservation in place; elapsed time alone does not release it. Quota data is not sent to Lemon Squeezy.

Downloaded files are saved through your browser to a location you choose or its configured download folder. They can contain sensitive website content. Deleting preferences or uninstalling the extension does not remove your downloaded files. Files that you later share, upload, or open in another service are subject to that service's practices.

4. Browser permissions

The extension requests activeTab to access the selected page when you invoke it, scripting for table detection and validation, storage for local preferences, licensing and quota records, and downloads to start local CSV/XLSX downloads, inspect their state, cancel interrupted transfers, and erase their download-history entries. Its host permission is limited to https://api.lemonsqueezy.com/* for licensing; it does not request general host access to every website or the separate history permission.

Downloads use local data URLs, which can temporarily expose exported table contents in browser download metadata. The extension attempts to erase its own completed download-history entries and confirmed non-resumable interrupted entries. Failed cleanup remains pending and is retried during reconciliation, including worker reload, browser startup, or subsequent use. Cleanup may be delayed by browser termination, storage errors, or browser API failures. Erasing a history entry does not delete the downloaded file or clear general browsing history.

5. Free quota and Pro licensing

Free includes five completed exports per browser installation, shared across CSV and XLSX, with no subscription. Pro provides unlimited exports, column customization, data cleanup, numeric Excel formatting, and saved preferences through a one-time lifetime license.

Pro activation, validation, and deactivation communicate over HTTPS with api.lemonsqueezy.com. Requests send the license key and, as needed, the activation instance ID or a generic installation label. They omit browser credentials and do not send table contents, page URLs, exported files, saved preferences, or quota data. Lemon Squeezy receives ordinary connection information such as the IP address used for the request. Provider responses may contain customer or order information; the extension does not persist those details.

Local license records contain the key, activation instance ID, status, last successful validation time, known expiration, and retry failure count/timing. Activation recovery markers may remain after an interrupted activation or failed local write. License keys are not encrypted against someone with access to the browser profile. Validation normally occurs after about seven days of use; failed checks retry on use with delays from one minute up to one hour. Offline access is limited to 30 days after the last successful validation and never overrides known expiration. Definitive invalid, revoked, expired, wrong-product, or wrong-instance responses disable Pro access.

Successful online deactivation removes local license details and releases the provider instance. Uninstalling or clearing extension storage can remove local preferences, licensing and quota state and reset the local trial, but does not free a provider activation slot. Deactivate online before uninstalling if you want to free that slot. The extension and this website do not collect payment details; no production checkout URL is provided here.

6. This website and GitHub Pages

This website uses static HTML, CSS, and locally hosted images. It contains no JavaScript, forms, analytics, advertising, cookies, browser-storage features, or tracking code. It does not read your tables or communicate with the extension.

When hosted on GitHub Pages, GitHub receives the requests needed to deliver these pages and assets. GitHub states that visitor IP addresses are logged and stored for security purposes. Hosting-related processing is separate from the extension's local table processing. See GitHub Pages documentation and the GitHub Privacy Statement.

If you follow a link to GitHub or another external website, that service's privacy practices apply. No table content or preference data is attached to links on this website.

7. Policy updates and project information

Changes to data handling will be reflected here with an updated date. Website source and project information are available in the public Smart Table Export website repository. Avoid posting private table contents, exported files, or sensitive website identifiers publicly.
