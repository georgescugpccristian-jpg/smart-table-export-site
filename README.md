# Smart Table Export website

Static, English-only product website: HTML, CSS, and local PNG assets. No framework, JavaScript, external fonts, analytics, cookies, dependencies, or build step.

## Preview locally

Open `index.html` directly in a browser, or serve this directory using an existing static file server. All page and asset links are relative and support the GitHub Pages project path `/smart-table-export-site/`.

## Public repository and GitHub Pages

This repository contains only the product website. It contains no extension source, extension manifest, tests, credentials, or development history from the extension project. Links labeled Website repository point to this public repository, not to extension source.

Repository: https://github.com/georgescugpccristian-jpg/smart-table-export-site

1. Push the website files to `main`.
2. Open **Settings → Pages** in this repository.
3. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/ (root)**, and click **Save**.
4. Wait for the Pages deployment in **Actions** to succeed. Enable **Enforce HTTPS** when available.
5. Check the homepage, Privacy Policy, images, and mobile layout at the URLs below.

Homepage: https://georgescugpccristian-jpg.github.io/smart-table-export-site/

Privacy Policy: https://georgescugpccristian-jpg.github.io/smart-table-export-site/privacy.html

`.nojekyll` keeps the site static. No custom build workflow or custom domain is required.
