01 / EXPORT

CSV and Excel, built in

Save loaded table data as CSV or native XLSX. XLSX uses Text columns by default to preserve identifiers and leading zeros. Spreadsheet-safe CSV is enabled by default.

02 / CUSTOMIZE

The right columns, in order

Select, reorder, and rename columns. Choose how headers are handled, then review the result before downloading.

03 / CLEAN UP

A cleaner starting point

Trim surrounding whitespace, remove completely empty rows, and remove exact duplicate rows. Cleanup applies to exported data, leaving the source table untouched.

04 / NUMBERS

Excel numbers, by choice

Choose English or Romanian numeric formats for individual XLSX columns. Strict validation flags unsafe conversions; other columns stay as text.

05 / REUSE

Save your export preferences

Reuse column settings and cleanup options on matching tables. Apply saved preferences explicitly, then refresh the preview. Changed or ambiguous tables are rejected.

06 / PRIVACY

Your tables stay local

Table detection, preview, cleanup, and file generation happen in your browser. The current extension makes no external requests and sends no table data to a server.

A straightforward workflow

Find it. Check it. Export it.

  1. Find a table

    Open the extension on a page and scan its loaded HTML tables.

  2. Prepare your export

    Adjust settings and update the export preview to validate the full table.

  3. Save your file

    Download CSV or XLSX for use in your spreadsheet application.

A clear scope: only currently loaded, visible rows in main-page HTML tables are supported. Unloaded pages, div/ARIA grids, embedded frames, shadow DOM, and merged cells are not supported. Oversized exports are rejected rather than truncated.
